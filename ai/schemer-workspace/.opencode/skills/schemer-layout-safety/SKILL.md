# Layout Safety

- Never propose coordinates, dimensions, mobile order, or viewport offsets.
- Schemer chooses placement for new or duplicated widgets.
- Rename and delete proposals must not modify unrelated widget layout.
- Preserve every existing widget's order and desktop/mobile layout unless the user uses Schemer's layout controls.
